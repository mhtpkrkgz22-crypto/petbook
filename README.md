# Pet Lovers Landing Page

A modern, high-contrast landing page designed for a pet community. This project is a practical implementation of a multi-section web design, emphasizing structural hierarchy, Flexbox layouts, and clean CSS styling.

## 🚀 Project Overview

This landing page provides a user-friendly interface divided into several key functional areas:

* **Hero Section:** A dark-themed header featuring a logo, navigation links, and a primary Call-To-Action (CTA).
* **Content Gallery:** A grid showcasing various pets with descriptions, styled with a distinct blue border theme.
* **Quote Section:** A dedicated space for educational pet facts or testimonials with a subtle background contrast.
* **Engagement Banner:** A highlighted "Sign Up" section to encourage user interaction.

## ✨ Technical Features

* **Flexbox Mastery:** Used extensively for aligning the header, centering the content gallery, and creating the responsive CTA banner.
* **Interactive UI:** Includes `:hover` state transitions on buttons for enhanced user experience.
* **Typography:** Integrated **Roboto** font family with specific weights (300, 400, 900) to match professional design standards.
* **Box Sizing:** Implemented `border-box` sizing globally for predictable layout management.

## 🛠️ Built With

* **HTML5:** Semantic structure for better accessibility and SEO.
* **CSS3:** Custom styles including Flexbox positioning and hover effects.
    * **Primary Colors:** Deep Blue (`#1F2937`), Vibrant Blue (`#3882F6`), and Light Gray (`#E5E7EB`).
